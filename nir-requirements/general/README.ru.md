# Общие требования

Документы описывают единые ожидания для всех типов НИР и студенческих проектов: доказательность, сравнение, воспроизводимость, артефакты, репозиторий, презентацию и защиту.

- [Памятка студенту](student.ru.md) — что должен доказать сильный проект и какие недостатки ограничивают оценку.
- [Памятка руководителю](supervisor.ru.md) — как сформулировать, сопровождать и проверить проект.
