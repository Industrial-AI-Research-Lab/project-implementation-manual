# Recommendations

Practical guides for running a student project: how to work with literature, the repository, and the task list. They complement the requirements and do not replace them.

- [Scientific papers](papers/README.md) — finding, saving, and reading papers; the paper collection and the reading log, which the supervisor can use to check the work.
- [Repository and code work](repository/README.md) — pull requests, the decision log, experiments in MLflow, automatic checks; student and supervisor editions plus optional commit-message rules.
- [Task tracking](task-tracking/README.md) — a board next to the code, experiments as issues, reports and meeting records; student and supervisor editions plus an optional meeting-records reference.
- [Agent artifacts](agents/README.md) — instruction files, shared agent settings, overlay repositories, and one check for the agent, pre-commit and CI.
