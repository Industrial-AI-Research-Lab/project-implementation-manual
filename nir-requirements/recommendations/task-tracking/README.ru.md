# Трекинг задач

Доска задач рядом с кодом, эксперименты в виде issues, отчёты и записи встреч.

- [Памятка студенту](student.ru.md) — доска, поля и представления, эксперименты в виде issues, план семестра, отчёты и встречи, минимальный ожидаемый результат.
- [Памятка руководителю](supervisor.ru.md) — первая неделя, еженедельный просмотр доски, встречи, перепланирование, как по доске подготовиться к контрольной точке, чек-лист.
- [Записи встреч](meeting-records.ru.md) — необязательная справка: расшифровка, очистка от персональных и конфиденциальных данных и промпты, по которым LLM-ассистент составляет запись встречи из расшифровки.
