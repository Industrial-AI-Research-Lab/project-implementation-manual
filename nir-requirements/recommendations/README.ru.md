# Рекомендации

Практические памятки по ведению студенческого проекта: работа с литературой, репозиторием и списком задач. Они дополняют требования и не заменяют их.

- [Научные статьи](papers/README.ru.md) — поиск, сохранение и чтение статей; коллекция и журнал чтения как проверяемые артефакты.
- [Репозиторий и работа с кодом](repository/README.ru.md) — pull request, решения, эксперименты в MLflow, автоматические проверки; редакции для студента и руководителя плюс необязательные правила сообщений коммитов.
- [Трекинг задач](task-tracking/README.ru.md) — доска рядом с кодом, эксперименты как issues, отчёты и записи встреч; редакции для студента и руководителя плюс необязательная справка о записях встреч.
