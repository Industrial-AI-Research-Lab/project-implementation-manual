# Рекомендации

Практические памятки по ведению студенческого проекта: работа с литературой, репозиторием и списком задач. Они дополняют требования и не заменяют их.

- [Научные статьи](papers/README.ru.md) — поиск, сохранение и чтение статей; коллекция статей и журнал чтения, по которым руководитель может проверить работу.
- [Репозиторий и работа с кодом](repository/README.ru.md) — pull request, журнал решений, эксперименты в MLflow, автоматические проверки; отдельные памятки для студента и для руководителя, а также необязательные правила оформления сообщений коммитов.
- [Трекинг задач](task-tracking/README.ru.md) — доска рядом с кодом, эксперименты как issues, отчёты и записи встреч; редакции для студента и руководителя плюс необязательная справка о записях встреч.
- [Агентные артефакты](agents/README.ru.md) — файлы инструкций, общие настройки агентов, overlay-репозитории и одна проверка для агента, pre-commit и CI.
