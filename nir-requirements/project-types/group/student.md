# Group Project — Guidance for Students

> This project type is an additional format available only after a supervisor submits an application. This document is intended for participants in an already approved group project and must not be distributed generally as a self-selection option.

A group project is a single complex task whose scale must correspond to the combined work of all participants.

For N participants, the volume and complexity must be comparable to **N complete individual projects**.

## What matters for each participant

- have an independent, substantively significant area of responsibility;
- perform professionally challenging work rather than supporting tasks alone;
- produce a result that can be identified and evaluated separately;
- be able to demonstrate their contribution;
- understand how their part relates to the other components;
- integrate the result into the unified project outcome; and
- meet deadlines and work effectively with the team.

A high grade is impossible when one small individual project is merely divided formally among several people.

## Required results

- a shared public repository in which all participants are contributors and authorship of code sections can be evaluated;
- a shared presentation covering the problem statement, architecture, division of work, implementation process, and results;
- an individual report from each participant describing their part, result, and contribution;
- a description of task allocation and relationships among components;
- a demonstration of the working result where applicable;
- an assessment of each participant's contribution by the supervisor or team members; and
- where necessary, evidence through commits, an issue or task tracker, experiments, documentation, and other artifacts.

## Requirements for 5A

The project must simultaneously have sufficient scale, a unified integrated result, quantitative comparison with alternatives, reproducibility, and a high-quality repository and documentation. Every participant must be able to explain their part and its relationship to the other parts.

## Formal caps

- if the volume is substantially below the participants' combined expected workload, the maximum grade is **4C**;
- if individual contributions cannot be identified, the maximum grade is **4C**.

## Common failures

- one or two people perform most of the work;
- roles are merely formal;
- some participants are underloaded;
- components are weakly connected;
- integration exists only in claims; or
- individual contributions are difficult to substantiate.
