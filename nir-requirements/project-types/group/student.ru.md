# Групповой проект — нюансы для студента

> Этот тип проекта является дополнительным форматом и по исходным правилам используется только после заявки руководителя. Файл предназначен для участников уже утверждённого группового проекта, а не для общего распространения как варианта самостоятельного выбора.

Групповой проект — единая комплексная задача, масштаб которой должен соответствовать суммарной работе всех участников.

Для N участников объём и сложность должны быть сопоставимы с **N полноценными индивидуальными проектами**.

## Что важно лично для каждого участника

- иметь самостоятельную содержательно значимую зону ответственности;
- выполнять профессионально сложные, а не только вспомогательные задачи;
- иметь результат, который можно идентифицировать и оценить отдельно;
- уметь доказать свой вклад;
- понимать взаимосвязь своей части с остальными компонентами;
- интегрировать результат в единый итог проекта;
- соблюдать сроки и работать с командой.

Нельзя получить высокий результат, если одну небольшую индивидуальную работу просто формально поделили между несколькими людьми.

## Обязательные результаты

- общий открытый репозиторий, где все участники являются контрибьюторами и можно оценить авторство блоков кода;
- общая презентация с постановкой, архитектурой, распределением работ, ходом реализации и результатами;
- индивидуальный отчёт каждого участника с описанием своей части, результата и вклада;
- описание распределения задач и связей между компонентами;
- демонстрация работающего результата, если применимо;
- оценка вклада каждого участника руководителем и/или членами команды;
- при необходимости подтверждение через коммиты, issue/task-трекер, эксперименты, документацию и другие артефакты.

## На 5А

Проект должен одновременно иметь достаточный масштаб, интегрированный единый результат, количественное сравнение с аналогами, воспроизводимость, качественный репозиторий и документацию. Каждый участник должен уметь объяснить свою часть и её связь с другими частями.

## Формальные ограничения

- если объём существенно меньше суммарного объёма работ участников → максимум **4С**;
- если невозможно определить индивидуальный вклад → максимум **4С**.

## Типичные провалы

- основную работу выполнили 1–2 человека;
- роли формальны;
- отдельные участники недогружены;
- компоненты слабо связаны;
- интеграция существует только на словах;
- индивидуальные вклады трудно подтвердить.
