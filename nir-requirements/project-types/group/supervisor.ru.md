# Групповой проект — нюансы для руководителя

Групповой проект — дополнительный формат **только по заявке руководителя НИР** и, согласно новому документу, **только для студентов 1 курса**.

Студенты не должны самостоятельно собираться в группу для выполнения такого проекта. В исходном документе отдельно указано: не рассказывать студентам об этом типе проекта до появления заявок от руководителей.

## Ключевой принцип масштаба

Для N участников проект должен быть сопоставим по объёму и сложности с N индивидуальными проектами.

Это должна быть единая комплексная задача. Механическое разбиение небольшой задачи на N фрагментов недопустимо.

При этом **не требуется делить проект на N формальных подтем**: у участников должны быть самостоятельные содержательно значимые зоны ответственности внутри одной темы и одного интегрированного результата.

## Что нужно обосновать до запуска

- почему задача требует команды такого размера;
- какие самостоятельные сложные зоны ответственности есть у каждого участника;
- как результаты участников образуют единую систему/исследование;
- как будет измеряться общий результат;
- как будет доказываться индивидуальное авторство и вклад;
- каким образом проект даст объём, эквивалентный N индивидуальным работам.

## Что отслеживать в течение проекта

- общий репозиторий и историю коммитов;
- issue/task-трекер или иной журнал задач;
- распределение зон ответственности;
- интеграционные точки между компонентами;
- измеримые результаты каждого участника;
- отсутствие ситуации, когда основную работу фактически делают 1–2 человека;
- документацию архитектуры и интерфейсов между частями.

## Обязательные артефакты

- общий открытый репозиторий всех участников;
- общая презентация с архитектурой и распределением работ;
- индивидуальный отчёт каждого участника;
- описание распределения задач и взаимосвязей;
- демонстрация работающего результата, если применимо;
- оценка вклада каждого участника;
- доказательства вклада при необходимости.

## На 5А

Нужны одновременно: масштаб N индивидуальных проектов, содержательные индивидуальные зоны, единый интегрированный результат, количественное сравнение с аналогами, воспроизводимость, качественная документация и способность каждого участника объяснить не только свою часть, но и её связь с другими.

## Формальные ограничители

- недостаточный масштаб → максимум **4С**;
- невозможность определить индивидуальный вклад → максимум **4С**;
- искусственно разделённая небольшая индивидуальная работа не может быть сильным групповым проектом.
