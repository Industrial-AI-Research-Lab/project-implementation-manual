# Типы проектов

Рекомендации по типам проектов дополняют общие требования и описывают характерные артефакты, риски и фокус оценивания каждого формата.

- [Научный проект](scientific/README.ru.md) — научная новизна, методология, эксперименты и готовность к публикации.
- [Технологический проект](technological/README.ru.md) — техническая новизна, архитектура, инженерное качество и бенчмаркинг.
- [Индустриальный проект](industrial/README.ru.md) — практическая ценность, измеримый эффект, потенциал внедрения и подтверждение заказчика.
- [Коллаборативный проект](collaborative/README.ru.md) — индивидуальный вклад в существующую команду.
- [Групповой проект](group/README.ru.md) — единый интегрированный проект масштаба, соответствующего суммарной работе участников.
