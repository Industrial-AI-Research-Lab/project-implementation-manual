# Project Types

Project-type guidance supplements the general requirements with the artifacts, risks, and assessment focus specific to each format.

- [Scientific project](scientific/README.md) — scientific novelty, methodology, experiments, and publication readiness.
- [Technological project](technological/README.md) — technical novelty, architecture, engineering quality, and benchmarking.
- [Industrial project](industrial/README.md) — practical value, measurable impact, deployment potential, and customer confirmation.
- [Collaborative project](collaborative/README.md) — individual contribution within an existing team.
- [Group project](group/README.md) — a single integrated project whose scale matches the combined work of all participants.
