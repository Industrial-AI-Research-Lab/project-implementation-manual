# Коллаборативный проект — нюансы для руководителя

Этот файл дополняет общие требования. В коллаборативном проекте ключевой объект оценки — индивидуальный вклад студента в реальный командный результат.

## При постановке

У студента должна быть заранее определена содержательно значимая зона ответственности, по которой можно отдельно оценить:

- техническую/исследовательскую сложность;
- самостоятельность;
- качество результата;
- соблюдение сроков;
- интеграцию;
- влияние на общий проект.

Зона ответственности не должна сводиться к роли «помогал команде», обслуживающим задачам или работе, авторство которой невозможно отделить.

## Что отслеживать

- задачи и сроки фиксируются так, чтобы вклад можно было восстановить;
- результат студента интегрируется в общий проект;
- есть понятные артефакты его работы и документация;
- студент понимает общую архитектуру, а не только локальный код;
- команда может дать содержательную оценку профессионального вклада и soft skills.

## На 5А

Нужен самостоятельный значимый вклад, регулярная эффективная коммуникация, соблюдение сроков, качественная интеграция и подтверждение командного вклада. Формальное участие недостаточно.

## Критические риски

- вклад неотделим от работы других;
- задачи слишком простые или вспомогательные;
- результат не интегрирован;
- систематические задержки;
- команда фактически заменяет студента в выполнении его части;
- студент не понимает общей системы.
