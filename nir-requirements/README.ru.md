# Требования к НИР

В разделе собраны общие требования, правила оценивания, особенности отдельных типов проектов, практические рекомендации и переиспользуемый контекст для LLM-ассистента, сопровождающего проекты НИР.

## Разделы

- [Общие требования](general/README.ru.md) — рекомендации, применимые ко всем типам проектов.
