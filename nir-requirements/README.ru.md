# Требования к НИР

В разделе собраны общие требования, правила оценивания, особенности отдельных типов проектов и переиспользуемый контекст для LLM-ассистента, сопровождающего проекты НИР.

## Разделы

- [Общие требования](general/README.ru.md) — рекомендации, применимые ко всем типам проектов.
- [Оценивание](assessment/README.ru.md) — уровни оценок, формальные ограничители, матрицы и чек-листы защиты.
- [Типы проектов](project-types/README.ru.md) — рекомендации студентам и руководителям по каждому типу проекта.
- [LLM-ассистент](llm-assistant/README.ru.md) — контекст для формирования и проверки тем.
