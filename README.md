# Student Project Implementation Manual

[Русская версия](README.ru.md)

> [!IMPORTANT]
> This repository is a working collection and is not currently an official instruction or regulatory document. Verify formal requirements with the responsible academic program and your supervisor.

This repository collects requirements, recommendations, templates, and methodological materials for student projects. It currently covers descriptions and requirements for NIR projects and a set of research templates.

## Current materials

- [NIR requirements](nir-requirements/README.md) — shared requirements, assessment guidance, project-type guidance, and context for an LLM assistant.
- [Research templates](research-templates/README.md) — a methodological template set for planning, conducting, documenting, and reviewing a study: from the research brief, questions, and hypotheses to the experimental protocol, data, analysis, reproducibility, ethics, publication, and review checklists. It suits both beginner and experienced researchers, explains non-obvious terms in a glossary on each page, and includes a guide for LLM agents.

Additional recommendations, templates, and methodological manuals may be added in later iterations.
