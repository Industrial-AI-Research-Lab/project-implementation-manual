# Руководство по выполнению студенческих проектов

[English version](README.md)

> [!IMPORTANT]
> Этот репозиторий является рабочей коллекцией и пока не представляет собой официальную инструкцию или нормативный документ. Формальные требования необходимо сверять с актуальными правилами образовательной программы и уточнять у руководителя.

В репозитории собраны требования, рекомендации, шаблоны и методические материалы для студенческих проектов. Сейчас материалы охватывают проекты НИР: требования, правила оценивания и практические памятки о научных статьях, работе с репозиторием, трекинге задач и агентных артефактах.

## Текущие материалы

- [Требования к НИР](nir-requirements/README.ru.md) — общие требования, правила оценивания, рекомендации по типам проектов, практические памятки и контекст для LLM-ассистента.

Материалы для других типов проектов, шаблоны и методические пособия могут появиться позже.
